## 문제의 성격 — 이번 대회는 OCR 문제다

train 6,714건 전수 분석 ([`docs/EDA.md`](docs/EDA.md)):

- 질문의 90% 이상이 **이미지 속 글자 판독** (상호·이름 25.8%, 문구·판독 21.4%, 가격·할인 13.7% …).
  1차 대회의 카운팅·재질 판별은 사실상 사라졌다 (카운팅 0.2%).
- 보기가 매우 비슷하다. **보기의 44.8%가 2글자 이내로 갈린다.**
  ```
  a) 1,800원   b) 1,300원   c) 1,200원   d) 1,700원
  ```
- `dev.csv`는 정답이 아니라 교육생 5명 응답이며, 4명 이상 일치가 0건이다 → 사용하지 않는다.

## 접근

| 단계 | 내용 | 효과 (홀드아웃) |
|---|---|---|
| 모델 선택 | Qwen2.5-VL-3B → 7B → **Qwen3-VL-8B / 32B** | 제로샷 0.860 → 0.9295 (8B) / 0.9375 (32B) |
| 해상도 | 768 → **1024** (하한·상한 픽셀 분리) | 8B 제로샷 +0.8%p, 7B 제로샷 +1.0%p |
| 추론 | 생성 대신 **로짓 스코어링** (a/b/c/d 4개 로짓 → softmax) | 파싱 실패 0, 확률을 앙상블에 재사용 |
| 학습 | 4bit QLoRA (r=16), **choice_ce 손실 + 보기 셔플** | 8B: 0.9375 → 0.9555 (1024, 4714건) |
| OCR 채널 | EasyOCR 텍스트 → 보기 문자열 매칭 점수 | 단독 49%, 모델이 약할 때 앙상블에 +0.25%p |
| 앙상블 | 서로 다른 모델의 확률 **균등 평균** | 0.9555 → 0.9625 |

**앙상블은 균등 평균만 쓴다.** 홀드아웃에서 가중치를 탐색하면 과적합된다
(탐색 0.958 → 반분 검증 0.9525 → LB 0.95084, 균등 0.9565 → LB 0.95174).

## 실행 (코랩, A100)

1. `notebooks/baseline_v10_1_TEMPLATE.ipynb`를 **드라이브에 사본 저장** → 이름을 `baseline_v10_1_<이름>`으로
2. 0번 셀에서 `WHO`(본인 이름), `ZIP_PW`, `MODEL_SIZE`, `IMAGE_SIZE`, `TRAIN_N` 설정
3. 셀 번호대로 실행

| 셀 | 내용 |
|---|---|
| 0~5 | 설정 · 설치 · 임포트 · 데이터(zip 해제 40초) · 질문 유형 · 프롬프트 |
| 6 | `load_model("q3_8b")` — 모델 교체는 이 셀만 다시 |
| 7 | 추론 함수 (로짓 스코어링, 이미지 로딩을 백그라운드에서 미리) |

| 9 | **앙상블 → 제출** (GPU 없이 확률 파일만으로 동작, 멤버별 기여도 출력) |
| 10~12 | Dataset 검증 · 학습 · 평가 |
| 13~14 | test 추론 · 제출 체크 |

## 공통 규칙

- **`VALID_N = 2000`, `SEED = 42`는 바꾸지 않는다.** 팀 전원이 같은 홀드아웃을 써야 확률을 섞을 수 있다.
  풀학습은 `TRAIN_N = 4714`(= 6714 − 2000).
- 확률 파일은 `save_path` 방식으로만 만든다 (파일이 있으면 불러오기만). 덮어쓰기 사고 방지.
- 학습이 끝난 세션에서 다른 모델을 올릴 때 메모리 부족이 나면 **런타임 → 세션 다시 시작**.
- 실험 결과는 전부 `docs/EXPERIMENTS.md`에 한 줄씩 기록한다. 제출 전에 먼저 기록한다.

### 제출

- 캐글 제출 한도는 **팀 하루 20회 공유**. 제출하면 단톡에 한 줄 남긴다.
- 파일명·설명란에 구성과 홀드아웃 점수를 적는다.
  예: `sub_ens_equal_7b_zs_8b_ft768_8b_ft1024_32b_ft_ocr_H2000_0.9625.csv`
- 최종 채점 대상 2개는 팀장이 확정한다.

### 깃

- 브랜치는 `main` 하나. **push 전에 항상 pull.**
- 노트북은 커밋 전에 출력 지우기(Restart & Clear All Outputs).
- ⚠️ **`ZIP_PW`(압축 암호)가 채워진 노트북은 올리지 않는다.** TEMPLATE만 올린다.
