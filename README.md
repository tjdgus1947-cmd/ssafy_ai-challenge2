# SSAFY 16기 2회차 AI 챌린지 — 텍스트 이미지 기반 VQA

대전 6반 · 4인 팀 **"감자 안심은 감자밭"** · 2026.09.21 ~ 09.28

이미지와 질문, 4지선다 보기(a/b/c/d)가 주어지면 정답 보기를 예측한다. (평가: Accuracy)

---

## 현재 성적 (09/23 기준)

| | 홀드아웃 (H2000) | LB (public) |
|---|---|---|
| **팀 최고** — 4모델 균등 평균 | **0.9690** | **0.96336** |
| 단일 모델 최고 — Qwen3-VL-32B, 768px, 4714건 학습 | 0.9585 | — |

최고 앙상블 구성: Qwen2.5-VL-7B 제로샷 · Qwen3-VL-8B 학습(768) · Qwen3-VL-32B 학습(768) · Qwen3-VL-32B 학습(1024)

### 핵심 결론
1. **글자 판독 문제지만, 가장 잘 읽는 OCR은 VLM 자신이었다.** 외부 OCR 단독 49% vs VLM 93%+
2. **입력 보강(OCR 주입 · 고해상도)은 모델이 강해지면 효과가 사라진다.** OCR 주입 +1.2%p → 학습 후 −0.1%p
3. **앙상블에는 센 모델보다 다르게 틀리는 모델이 필요하다.** 7B 제로샷을 학습본으로 바꾸면 오히려 하락
4. **가중치는 균등, 멤버 선택은 반분 검증** (앞 1000 · 뒤 1000 양쪽에서 오를 때만 채택)

점수 변화와 모든 실험은 [`docs/EXPERIMENTS.md`](docs/EXPERIMENTS.md)에 있다.

## 문제의 성격 — 이번 대회는 OCR 문제다

train 6,714건 전수 분석 ([`docs/EDA.md`](docs/EDA.md)):

- 질문의 90% 이상이 **이미지 속 글자 판독** (상호·이름 25.8%, 문구·판독 21.4%, 가격·할인 13.7% …).
  1차 대회의 카운팅·재질 판별은 사실상 사라졌다 (카운팅 0.2%).
- 보기가 매우 비슷하다. **보기의 44.8%가 2글자 이내로 갈린다.**
  ```
  a) 1,800원   b) 1,300원   c) 1,200원   d) 1,700원
  ```
- `dev.csv`는 정답이 아니라 교육생 5명 응답이며, 4명 이상 일치가 0건이다 → 사용하지 않는다.

## 접근

| 단계 | 내용 | 효과 (홀드아웃) |
|---|---|---|
| 모델 선택 | Qwen2.5-VL-3B → 7B → **Qwen3-VL-8B / 32B** | 제로샷(768) 0.860 → 0.9295 (8B) / 0.9375 (32B) |
| 해상도 | 768 → **1024** (하한·상한 픽셀 분리) | 제로샷 +0.8%p. 학습 후(32B)엔 효과 없음 |
| 추론 | 생성 대신 **로짓 스코어링** (a/b/c/d 4개 로짓 → softmax) | 파싱 실패 0, 확률을 앙상블에 재사용 |
| 학습 | 4bit QLoRA (r=16), **choice_ce 손실 + 보기 셔플** | 8B 1024: 0.9375 → 0.9555 / 32B 768: 0.9375 → 0.9585 |
| OCR 채널 | EasyOCR 매칭 점수 · OCR 텍스트 프롬프트 주입 | 매칭 단독 49%. 주입은 제로샷 +1.2%p → 학습 후 효과 없음 |
| 앙상블 | 서로 다른 모델의 확률 **균등 평균** + 반분 검증 멤버 선택 | 0.9585 → 0.9690 |

**앙상블은 균등 평균만 쓴다.** 홀드아웃에서 가중치를 탐색하면 과적합된다
(탐색 0.958 → 반분 검증 0.9525 → LB 0.95084, 균등 0.9565 → LB 0.95174).
**멤버는 H2000을 앞/뒤 1000건으로 나눠 양쪽에서 모두 오를 때만 추가한다.**

## 실행 (코랩, A100)

1. `notebooks/baseline_v10_2_TEMPLATE.ipynb`를 **드라이브에 사본 저장** → 이름을 `baseline_v10_2_<이름>`으로

3. 학습만 할 때는 `RUN_ENSEMBLE = False` 두고 **런타임 → 모두 실행** (한 번에 끝까지 돈다)

## 공통 규칙

- **`VALID_N = 2000`, `SEED = 42`는 바꾸지 않는다.** 팀 전원이 같은 홀드아웃을 써야 확률을 섞을 수 있다.
  풀학습은 `TRAIN_N = 4714`(= 6714 − 2000).
- 확률 파일은 `save_path` 방식으로만 만든다 (파일이 있으면 불러오기만). 덮어쓰기 사고 방지.
- 학습이 끝난 세션에서 다른 모델을 올릴 때 메모리 부족이 나면 **런타임 → 세션 다시 시작**.
- 실험 결과는 전부 `docs/EXPERIMENTS.md`에 한 줄씩 기록한다. 제출 전에 먼저 기록한다.

### 제출

- 캐글 제출 한도는 **팀 하루 20회 공유**. 제출하면 단톡에 한 줄 남긴다.
- 파일명·설명란에 구성과 홀드아웃 점수를 적는다.
