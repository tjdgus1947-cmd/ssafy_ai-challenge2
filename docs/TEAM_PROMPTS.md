## 역할

| 이름 | 역할 | 하는 일 | 결과물 |
|---|---|---|---|
| 김성현 | ① 모델 · TEMPLATE · 앙상블 | 새 모델 제로샷 평가, 공통 노트북 관리, 팀원 결과를 모아 앙상블 조립 | 앙상블 제출 파일, TEMPLATE |

| 이희원 | ③ OCR 채널 | OCR 캐시, 보기 매칭 점수, OCR 프롬프트 주입·focus crop 실험 | OCR 캐시·매칭 점수 파일 |
| 조은아 | ④ 분석 · 제출 · 발표 | 오답 원인 분류, 제출 관리, 발표 자료 | 오답 분석표, 발표 PPT |

## 재료 흐름

```
희원(OCR) ──캐시──▶ 정연(학습) ──확률 파일──▶ 성현(앙상블) ──제출 파일──▶ 은아(제출)
    └──매칭 점수───────────────────────────▶ 성현
은아(오답 분석) ──원인별 오답──▶ 정연 · 희원
```

| 보내는 사람 → 받는 사람 | 재료 | 형태 · 위치 |
|---|---|---|
| 성현 → 전원 | 팀 TEMPLATE | 깃허브 `notebooks/baseline_v10_2_TEMPLATE.ipynb` |
| 희원 → 정연 | OCR 캐시 (텍스트 + 박스) | `ssafy_ai/ocr/ocr_train.csv`, `ocr_test.csv` (id, ocr_text, n_box, ocr_json) |
| 희원 → 성현 | OCR 매칭 점수 | `ssafy_ai/ocr/ocr_scores_train.csv`(train 셔플 순서), `ocr_scores_test.csv` (id, score_a~d) |
| 정연 → 성현 | 학습 모델 확률 + TAG + 홀드아웃 점수 | `ssafy_ai/<WHO>/valid_<TAG>.pt`, `test_<TAG>_r0.pt` |
| 정연 → 은아 | 홀드아웃 예측 | `ssafy_ai/<WHO>/hold_pred_<TAG>.csv` |
| 성현 → 은아 | 앙상블 제출 파일 · 앙상블 홀드아웃 예측 | `sub_ens_equal_*.csv`, `hold_pred_ens_*.csv` (pred_모델별, n_right 포함) |
| 은아 → 정연·희원 | 오답 원인별 개수 + 예시 | `docs/EXPERIMENTS.md` 오답 분석 표 |
| 은아 → 전원 | LB 점수, 남은 제출 횟수 | 단톡 |

**넘길 때는 항상 "파일 경로 + TAG + 홀드아웃 점수" 세 개를 같이 보낸다.**

### 오답 원인 → 담당

| 코드 | 원인 | 담당 |
|---|---|---|
| A | 글자가 작거나 흐려서 못 읽음 | 정연(해상도) · 희원(focus crop) |
| B | 읽을 수 있는데 비슷한 보기와 혼동 | 희원(OCR 매칭) · 정연(학습) |

| E | 라벨 의심 | 기록만 |

## 공통 규칙

### 노트북
1. **TEMPLATE을 직접 실행하지 않는다.** 드라이브에 사본 저장 → `baseline_v10_2_<이름>`.
2. **`VALID_N = 2000`, `SEED = 42`는 바꾸지 않는다.** 바꾸면 홀드아웃이 달라져 앙상블에 못 넣는다.
3. 풀학습은 `TRAIN_N = 4714`. 6000이 아니다.
4. 학습 후 다른 모델을 올릴 때 메모리 부족이 나면 **런타임 → 세션 다시 시작**.
5. `ZIP_PW`가 들어간 사본은 깃허브에 올리지 않는다.

### GPU
- A100은 **동시에 2대까지**. 학습 두 개가 돌고 있으면 나머지는 L4(24GB)로 한다. 8B 4bit는 L4에서 추론 가능.
- 다 쓴 런타임은 **연결 해제**한다.

### 앙상블 · 제출
- 앙상블은 **균등 평균**. 가중치 탐색은 과적합된다 (EXPERIMENTS 실패 기록 참고).
- 새 멤버는 균등 평균에 넣었을 때 **H2000 앞 1000건 · 뒤 1000건 양쪽에서 모두 오를 때만** 추가한다 (`notebooks/ensemble_cpu.ipynb` 그리디).
- 단독 점수가 높다고 좋은 멤버가 아니다. **다르게 틀리는 모델**이 앙상블에 기여한다 (7B 제로샷 → 학습본 교체 시 하락).
- 캐글 제출은 팀 하루 20회 공유. 제출하면 단톡에 한 줄.

### 기록
- 모든 실험은 `docs/EXPERIMENTS.md`에 한 줄. 효과 없던 실험도 실패 기록에 적는다.

## 새 실험 체크리스트 (학습)

```
[ ] TEMPLATE v10.2 사본, WHO·ZIP_PW 채움
[ ] 0번: MODEL_SIZE / IMAGE_SIZE / TRAIN_N / EPOCHS 확인, VALID_N=2000·SEED=42 그대로
[ ] 0번: RUN_ENSEMBLE=False, (긴 학습이면) RUN_ZS_VALID=False
[ ] 런타임 → 모두 실행 (밤샘이면 맨 끝에 runtime.unassign() 셀 추가)
[ ] 10번 검증 전부 OK
[ ] 11번 첫 줄 TAG 확인
[ ] 12번 평가 → 13번 test 추론
[ ] TAG + 점수 공유, EXPERIMENTS.md 기록
```

## 새 모델 체크리스트 (제로샷, ①)

```
[ ] 0번 _HF 에 모델 등록, MODEL_SIZE 변경
[ ] 6번 출력: 이미지 토큰 수, LETTER_IDS 가 a/b/c/d 한 글자씩
[ ] 8번 첫 셀 (H2000) → 8번 두 번째 셀 RUN_ZS_TEST=True (test)
[ ] 9번 ENS 에 추가 → 균등 평균·멤버별 기여 확인
```
