# 실험 기록

**제출 전에 반드시 여기에 먼저 기록한다.** 발표 자료와 제출 문서가 이 표에서 나온다.
마지막 날 기억으로 재구성하려 하면 반드시 티가 난다.

기록 원칙
- **한 번에 변수 하나만 바꾼다.** 두 개를 동시에 바꾸면 "무엇이 얼마나 올렸다"고 말할 수 없다.
- 홀드아웃 500건의 오차는 약 **±1.3%p**다. 차이가 1%p 안쪽이면 "비슷함"으로 본다.
- `VALID_N` 을 바꾸면 홀드아웃 구성이 달라져 이전 점수와 직접 비교할 수 없다. 메모에 `H1000` 처럼 표시한다.

해석
- 모델 크기는 **추론형**(위치·주소, 부정형)을 가장 많이 올렸다.
- 번호·연락처 하락은 31문항 중 2문항 차이, 부정형 상승은 9문항 중 3문항 차이라 표본 흔들림 범위다.
- **메뉴·상품은 모델을 키워도 그대로** → 다른 원인이 있다. 오답 분석 대상.
